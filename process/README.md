# Process Files

## Purpose

> **Scope:** Index of the procedures under `process/`
> **Key items:** load order, shared contracts, pipeline files

Load a procedure only when the task reaches it - progressive disclosure stays lazy.

## Index

| File                    | When to load                                               |
|-------------------------|------------------------------------------------------------|
| `skill-activation.md`   | Bare activation - the request names the skill but no task  |
| `skill-maintenance.md`  | The request targets this repository's own files            |
| `json-exchange.md`      | JSON parameter requests, diagnostic mode, verbose surfaces |
| `decision-modes.md`     | Any operation run - the interaction-mode matrix            |
| `session-review.md`     | "Improve the skill from this session" requests             |
| `forge-workflow.md`     | Any generation operation - the five-phase pipeline         |
| `research-gathering.md` | Phase 1 intake - brief, inventory, plan, extraction        |
| `research-synthesis.md` | Phase 1 output - distillation into the rule map            |
| `source-conversion.md`  | A source needs binary/markup conversion                    |
| `skill-template.md`     | Phase 2-3 - what a generated skill must contain            |
| `layout-migration.md`   | Converting an existing skill between layout profiles       |
