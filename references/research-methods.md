# Research Methods

## Purpose

> **Scope:** Classifying the research task and picking the gathering methodology
> **Key items:** research types, depth levels, source categories, method selection

## Research Types

| Type         | Goal                                               | Skill shape it feeds              |
|--------------|----------------------------------------------------|-----------------------------------|
| Domain skill | Distill a subject area into procedures             | Router + process + references     |
| Method skill | Encode one methodology or framework                | Router + a focused process corpus |
| Tool skill   | Capture a tool's command surface and practice      | Router + references + scripts     |
| Source skill | Convert one authoritative document into skill form | Router + source-mapped rule files |

The type is a decision surface at intake - usually resolvable from the request
and the source inventory.

## Depth Levels

| Level      | Gathering bound                                       |
|------------|-------------------------------------------------------|
| Focused    | The supplied sources only                             |
| Extended   | Supplied sources plus individually approved additions |
| Exhaustive | Bounded multi-source survey with a recorded stop rule |

Deeper is not better when the question is narrow - match depth to the success
signal in the research brief.

## Source Categories

Prefer, in rough authority order:

1. Primary specifications, canonical documentation, the source text itself.
2. Official guides and maintained repositories.
3. Books and long-form treatments (converted per `process/source-conversion.md`).
4. Commentary, blogs, tertiary summaries - usable as context, flagged as such in
   provenance.

A claim resting only on category-4 evidence stays `likely` at best.

## Method Selection

- **Survey** for breadth questions - what approaches exist.
- **Deep extraction** for single-source skills - one book, one manual.
- **Comparative** for conflict-heavy domains - record positions, not verdicts,
  where sources genuinely disagree.

Record the chosen method in the gathering plan with its reason.
